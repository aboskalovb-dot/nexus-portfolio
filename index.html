Video editing concept

Shorts / Reels с субтитрами

Пример короткого вертикального ролика для блогера или игрового канала.

  • Убрать паузы и лишние фрагменты.
  • Добавить читаемые субтитры и акценты на важных словах.
  • Подобрать музыку и звуковые эффекты, выровнять громкость.
  • Сделать динамичное начало, чтобы удержать внимание.
Roblox UI concept

Магазин предметов и валюта

Пример GUI для симулятора или другой Roblox-игры.

  • Окно магазина с карточками предметов.
  • Отображение баланса игровой валюты.
  • Кнопки покупки и проверка, хватает ли игроку денег.
  • Связь интерфейса с серверной логикой через безопасные RemoteEvents.
Python concept

Сортировщик файлов

Пример небольшой программы для автоматизации порядка в папке загрузок.

  • Выбрать папку, с которой нужно работать.
  • Распознать типы файлов по расширению.
  • Разложить изображения, документы и видео по папкам.
  • Показать результат и обработать возможные ошибки.
